## The idea

Our team will build this project from scratch during the hackathon. The goal is to create an application inspired by the familiar RVTools workflow, while making it available across the platforms administrators use every day.

## What we’re building

<table>
  <tr>
    <td width="50%" valign="top">

      <p>One experience for macOS, Linux, and Windows.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Service-friendly on Linux</h3>
      <p>When deployed as a Linux service, the application will provide a web-based user interface.</p>
    </td>
  </tr>

## Hackathon goal

Deliver a useful, approachable tool that helps VMware administrators assess and explore their environment—without tying the experience to a single operating system.
